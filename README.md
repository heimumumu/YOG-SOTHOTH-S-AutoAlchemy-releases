# 耶耶龙的自动炼金

？！电表在自己转！？

给《犹格索托斯的庭院》做的自动电表倒转炼金工具。装备一星「炼金术士之骨」，准备好材料，就可以让程序帮你自动转电表，酒狐会自己转曲柄，现在耶耶龙也会！

耗费雷霆大精力写了一套决策算法，程序会看当前库存，智能判断哪些材料可以继续升级，缺了小材料就用沉淀物补料。
同样价值的原料优先选售价较低的，紫色、金色和已有的50成品会保留，还会智能决策是否使用炼金10次。
基本解放双手！

## 功能

- 自动选择配方、推进中间材料，支持沉淀物补料。
- 原料和后续预留足够时使用「炼金十次」，也可以设为只炼单次。
- 按实际新增的50成品统计完成轮数，补料只计入操作次数。
- 查看任务用时、材料库存和售价净变化，支持暂停与继续。

库存和材料身份默认通过只读内存读取，界面状态与结果仍需要画面核对。
如果通过内存读取时出现问题，程序会自动采用OCR识别画面确保运行稳定。

## 怎么用

1. 从本仓库 Releases 下载正式版EXE，双击后打开程序网页，后台常驻系统托盘。
2. 游戏进入自由炼金页面，材料按「炼金价值 ↓」排序，确认装备一星「炼金术士之骨」。
3. 在「运行设置」里填写目标轮数，勾选神谕确认并保存。
4. 扫描库存，核对材料后开始炼金。每次点击操作按钮，都要在8秒内切回游戏。

第一次建议先试「单次炼金」。运行时要让游戏保持在前台，切换窗口会暂停，F8也能暂停。

关闭网页后，后台服务仍会运行。双击时钟旁的托盘图标可以重新打开网页；退出程序请右键托盘图标，选择「退出程序」。图标可能在托盘的展开箭头里。

设置和故障处理见 [使用说明书](使用说明书.md)。

## 收益怎么看

页面显示的是任务前后库存按炼金页面售价计算的净变化，消耗的原料也算在里面。
材料需要自己卖，金币余额不会直接增加。
游戏有随机产出机制，同样的目标，换一份库存就可能用不同的配方，花不同的时间。
